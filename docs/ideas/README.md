# Ideas

## Other universes

Earnings transcripts were the first demo, not necessarily the best. Transcript/document universes in science and healthcare (trial readouts, FDA advisory-committee transcripts, grand rounds, conference Q&A) each fit the same shape: a skill plus a skill-specific toolset on the shared `subjects` / `runs` / `artifacts` model.

- [transcript-universes.md](./transcript-universes.md) — researched shortlist with obtainability checks.
- [zero-friction-universes.md](./zero-friction-universes.md) — candidates actually probed with `curl`: ECB/Fed HTML, ClinicalTrials.gov history JSON, IETF minutes.
