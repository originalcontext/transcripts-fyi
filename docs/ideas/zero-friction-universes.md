# Zero-friction demo universes

Date: 2026-08-29
Status: verified by shell probes on 2026-08-29. Every row below was tried with `curl -sL -A "Mozilla/5.0" <url>` for the listing and for one document; "status/size" is what came back. Companion to `transcript-universes.md` (the ranked shortlist); this note answers only "which of those can be wired as a demo with zero friction".

Zero friction = no key/sign-up/OAuth; plain HTTPS fetch from a Node/Vercel function returning text/HTML/JSON (no PDF parsing); predictable URLs or a simple index; no anti-bot 403 with a normal UA; permissive terms; one doc fits ~100k chars or splits trivially. "chars" = tag-stripped text length.

## Recommended for a demo this week

Ordered by (trivial fetch) x (longitudinal aha). Every URL below returned 200 to a plain `curl -A "Mozilla/5.0"` today.

### 1. Central banks: `fed` + `ecb` (subject kind `central_bank`)

Two subjects on day one, both HTML, both public/attributable, both keyed by meeting date.

- `list_cb_meetings(bank)`
  - `fed`: GET `https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm`; regex `/monetarypolicy/fomcminutes(\d{8})\.htm` and `/newsevents/pressreleases/monetary(\d{8})a\.htm` -> `[{date, statement_url, minutes_url}]`. Observed: 200 text/html 164,831B, dates back to 2021.
  - `ecb`: for each year GET `https://www.ecb.europa.eu/press/press_conference/monetary-policy-statement/{YYYY}/html/index_include.en.html`; regex `ecb\.is(\d{6})~[a-f0-9]+\.en\.html` -> `[{date, url}]`. Observed: 2025 include 200 62,909B (8 meetings); 2026 include 200 31,092B.
- `fetch_cb_document(bank, date, kind)`
  - `fed`, `kind in {statement, minutes}`: GET the URL from the list; strip tags. Observed: minutes 200 128,047B -> 55,965 chars; statement 200 82,158B -> 10,698 chars.
  - `ecb`, `kind = statement_qa`: GET `https://www.ecb.europa.eu/press/press_conference/monetary-policy-statement/{YYYY}/html/ecb.is{YYMMDD}~{hash}.en.html`; strip tags. Observed: 200 137,680B -> 45,271 chars, prepared statement + full journalist Q&A in one page.
- Aha: the ECB page is literally an earnings call for a currency (prepared remarks, then the same journalists asking the same question eight meetings running) - "when the President was asked about the next cut, the answer went from 'we are not pre-committing' to 'the direction is clear' to 'we are in a good place', and the deposit rate did X". For the Fed, statement-vs-minutes is guidance-vs-delivery: one changed word in the statement, and three weeks later the minutes show whether "several" became "most" participants.
- Cost: the FOMC press-conference Q&A is PDF-only and is deliberately left out; statement + minutes carry the guidance ledger without it.

### 2. ClinicalTrials.gov record history (subject kind `clinical_trial`, key = NCT ID)

- `list_trial_versions(nct)`: GET `https://clinicaltrials.gov/api/int/studies/{nct}/history` -> `changes[]` of `{version, date, status, moduleLabels[]}`. Observed: 200 application/json 5,394B for NCT04178941; `moduleLabels` already says which sections changed (e.g. `["Study Status","Contacts/Locations"]`), so the agent can skip administrative versions and jump to ones touching Outcomes / Design / Eligibility.
- `fetch_trial_version(nct, version)`: GET `https://clinicaltrials.gov/api/int/studies/{nct}/history/{version}` -> full record JSON at that version. Observed: 200 application/json 12,787B. Current record for comparison: `https://clinicaltrials.gov/api/v2/studies/{nct}?format=json` 200 44,663B.
- Aha: "the primary outcome was changed at version 14, four months before results were posted; enrollment target was cut from 1,200 to 640 at version 9; completion date slipped three times". Public domain, tiny payloads, thousands of subjects, and the diff is JSON-to-JSON so no diff tool is needed beyond a key-wise compare.
- Caveat: `/api/int/` is the site's internal endpoint (the documented v2 API has no history). It is what the site's own History tab and the `cthist` package use; fine for a demo, flag it for production.

### 3. IETF working-group minutes (subject kind `ietf_wg`, key = WG acronym)

- `list_wg_minutes(wg)`: GET `https://datatracker.ietf.org/api/v1/doc/document/?type=minutes&group__acronym={wg}&format=json&limit=50` -> `objects[].name` like `minutes-119-httpbis` (+ `time`). Observed: 200 application/json 3,403B for httpbis.
- `fetch_wg_minutes(name)`: parse `{num}` from `minutes-{num}-{wg}`; GET `https://datatracker.ietf.org/meeting/{num}/materials/{name}-00`. Observed: 200 text/html 36,397B -> 30,243 chars (rendered markdown; `https://datatracker.ietf.org/doc/{name}/` also 200). Interim minutes use names like `minutes-interim-{YYYY}-{wg}-{nn}-{stamp}`; same endpoint shape.
- Aha: "the same three objections to the draft's retry semantics were raised at 116, 117 and 118; at 119 the chair recorded consensus after the author dropped section 4.2". Fully open licence, documented read API, ~3 plenaries + interims per year per WG, 6-10 docs over two years.

Runners-up (all ✅ on fetch, weaker story or one unverified step): **Fed speeches per official** (`federalreserve.gov/newsevents/speech/{lastname}{YYYYMMDD}a.htm`, 36k chars each; the per-year archive page needed to list beyond the RSS window was not probed), **GitHub releases** (one JSON call returns bodies inline; 60/hr unauthenticated; most "changelog digest" of the lot), and **Oyez SCOTUS transcripts** (best story of the list - 82k chars, 345 speaker turns, per-Justice series in one JSON call - but an undocumented API with unverified reuse terms).

Not this week despite the ranking in `transcript-universes.md`: **DailyMed labels** (prior versions only via a 300KB HTML page at `drugInfo.cfm?setid=&version=`, ~146k chars per label; needs section splitting and a server-side diff before it demos well), **SEC comment letters** (needs the SEC-format User-Agent header and the series is sparse), **FOMC pressers, SCOTUS official, AdCom, ACIP, hearings** (PDF-only), **congress.gov / GovInfo** (403 / key).
